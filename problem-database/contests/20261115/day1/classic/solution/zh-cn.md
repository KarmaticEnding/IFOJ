# 经典问题：题解与部分分

原题：Codeforces 464E, The Classic Problem。
<https://codeforces.com/problemset/problem/464/E>
本场将边数上限改为 200000，其余核心任务不变。

## 各档做法

1. X<=40（12 分）：简单路径至多 n-1 条边，距离小于 n*2^40<2^57，使用 64 位整数 Dijkstra。
2. X-Y<=40（8 分）：所有边除以 2^Y，化为上一档。路径恢复后累加原始边权的模值。
3. 树（4 分）：唯一简单路径，遍历找出路径即可。
4. 连通且 m=n（8 分）：唯一环。剥去叶子或用生成树加一条非树边，最多比较三条候选简单路径；用线性二进制计数进位比较准确长度。不能把大指数作为普通整数边权。
5. 最多两种指数（16 分）：设两种指数 a<b。若 2^(b-a)<=n，则除以 2^a 后仍可用 64 位整数 Dijkstra；否则任意简单路径的小边总和小于一条大边，可按（大边数，小边数）字典序 Dijkstra。只有一种指数时退化为 BFS。
6. 指数互不相同（16 分）：一条大边严格大于所有指数更小的边的权值之和。将所有边按指数从小到大做 Kruskal，最小生成森林中 s 到 t 的路径即最短路。若非树边能改善树上路径，取该边与树上路径构成的环，环中最大指数边不可能已被 Kruskal 选入，矛盾。也可从任意路径与树路径的对称差中取最大指数边证明树路径更短。
7. n<=5000,m<=10000（24 分）：高精度整数 Dijkstra。采用只存顶点编号的可减小关键字堆，可将高精度距离限制为每点一份，通常能通过这一档。把每次松弛得到的大整数全部复制入堆可能有较大额外开销。
8. 完整数据（12 分）：可持久化二进制线段树与 Dijkstra。

以上分数是各档独立占比，不是互不重叠的算法得分承诺；较强算法也会通过某些较弱档。

## 完整做法

正权图可直接使用 Dijkstra，难点是距离的表示、加一个二的幂、以及准确比较。

一条简单路径的长度至多 (n-1)*2^X，所以只需要 X+ceil(log2(n))+O(1) 个二进制位。即使是一次非最优的松弛，至多多经过一条边，同一位宽仍足够。

用可持久化线段树表示位串。节点表示低位在左、高位在右的区间。根到叶的深度为 O(log(X+log n))。

### 加 2^x：整段跳过进位

从第 x 位开始加一。若某个完整区间全是 1，就将整段变成 0，并把进位送到下一区间；遇到第一个 0 时将它置 1，停止进位。每层仅会出现边界递归和一个继续进位的方向，整段全 1 会直接跳过，因此一次操作只创建 O(log(X+log n)) 个节点。

不能逐位翻转后声称二进制加法可以均摊。可持久化版本会被重复使用：同一个形如 ...011111 的旧距离，可以从很多条出边反复产生 ...100000。数据专门覆盖了这一情况。

### 精确比较：节点唯一化

为每一种内部节点的左右孩子编号对 (left,right) 分配唯一编号。叶子 0、1 的编号不同。由归纳可知，在相同高度上，两个节点编号相同，当且仅当它们表示的整段二进制串完全相同。

实现采用开放寻址散列表查询孩子编号对，命中时比较完整的 64 位编号对，冲突时继续探测。散列只用于查表加速，不将散列相等当作位串相等，因此答案没有散列碰撞误判。

比较两个根时，优先检查高位的右子树。若右子树编号不同，进入右子树；否则进入左子树。到叶子即可确定大小，耗时 O(log(X+log n))。

编号是全局唯一的语义编号，不能用普通持久化树“地址不同”判断字符串不同。普通持久化树的不同节点可能恰好存着相同位串。

### Dijkstra 与复杂度

每个顶点记录距离根、前驱顶点与前驱边指数。堆中的旧版本通过根编号检测过期。正权保证定点后距离不会改变，前驱恢复得到简单路径。由比较与加法都准确可知，Dijkstra 的通常正确性证明直接适用。

设 H=log(X+log n)。使用节点唯一化散列表，预期时间 O((n+m)*log n*H)，空间 O(n+m+m*H)。其中“预期”仅涉及散列表查找耗时，数值比较与结果均为精确计算。若要求完全确定的最坏界，可用有序映射唯一化节点，并相应增加查找的对数因子。

输出时沿前驱链累加 2^x mod 1000000007；不能先将距离取模后再做最短路。

## SPJ

正式 SPJ 根据两条路径的边指数计数，各自进位得到二进制位串后精确比较。
公开 SPJ 则对候选路径与参考路径的指数计数作差，逐位检查偶性并传递有符号进位；两者差为零当且仅当真实长度相等。
二者都检查端点、边存在、顶点不重复、路径长度上限、取模值、无路情形和多余输出。
`.ans` 保存完整参考路径。仅比较第一行模值不能保证输出的是最短路。

## 数据与验证

tools/verification.json 保存生成前对拍结果与源文件哈希。
tools/data-audit.json 保存每份数据的规模、指数集合、连通分量、标准程序资源实测、独立 oracle 类型与输入答案哈希。
tools/hardening-audit.json 保存错误算法实测。

独立 oracle 使用 Boost cpp_int 精确整数与可减小关键字堆，不复用标程的二进制树；特殊性质还分别使用归一化整数、唯一环枚举和 Kruskal 路径检查。
小图另由 Python 任意精度整数 Dijkstra 对拍，包括 s=t、空图、不连通、相同距离的不同路径、最大指数、长进位及取模碰撞。

正式大点覆盖大指数共同前缀、从同一旧版本反复长进位、包含等长路径及最小生成树/对数近似误判的串联结构，填充边不改变预设长进位的最短距离。一般档另有不同结构的随机连通图。
