# 前缀乘积

第一个条件为 a_1^2=b_1，所以 b_1 必须为完全平方数，且正整数 a_1 唯一。标准程序用整数二分求平方根，避免在 10^18 附近浮点舍入导致误判。

设前缀最小值 L、最大值 R 已确定。加入下一个正整数只可能有三种情况：

- b_i>b_{i-1}：最大值增大，最小值仍为 L，因此 a_i=b_i/L；必须整除。
- b_i<b_{i-1}：最小值减小，最大值仍为 R，因此 a_i=b_i/R；必须整除。
- b_i=b_{i-1}：a_i 可以取 [L,R] 内任意整数，共 R-L+1 种，新的最小值与最大值不变。

因此每一步的极值状态唯一，与之前具体选了哪一个内部值无关。方案数就是所有相等步骤的区间长度之积；发生不整除或首项非完全平方数时无解。
构造时，相等步骤任取 L，其余步骤使用唯一可选值即可。

方案数用模数 100000007 计算。先把 R-L+1 对模数取模，再与已有方案数相乘，否则 64 位乘法也可能溢出。模后为 0 与无解必须分别记录。
时间复杂度 O(n+log(max b_i))，空间 O(n) 用于保存输入和待输出构造。

部分分：前 10 分枚举 a_i（正整数条件保证 a_i<=b_i）；小值域档按当前最小值、最大值做 DP 并记录构造；单调不降档最小值固定；单调不增档最大值固定；完整解处理两种变化。

正式 SPJ 读取只含计数的 .ans，用 128 位乘法直接检查每个前缀。下发 SPJ 独立重算计数，使用整除判定检查构造，避免乘法溢出。两者都要求两行输出；无解必须是两行 -1；有解计数为 0 仍需合法构造。

tools/model.py 使用 Python 精确整数作为独立模型；小规模另用完整极值状态 DP 核对。测试覆盖 10^18 附近平方数、非平方数、两种方向及交替变化、计数为 0、计数为 0 后才无解、错误模数与不取模就乘导致的溢出。
